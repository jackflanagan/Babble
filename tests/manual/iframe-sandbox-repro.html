Babble — WebRTC multiplayer fallback repro (manual, not part of the Playwright suite)

This iframes the built game with sandbox="allow-scripts allow-same-origin" — deliberately missing most other sandbox tokens, closer to what a restrictive portal embed might look like.

Honest caveat: the sandbox attribute alone mostly does not disable WebRTC in current Chromium — it isn't one of the gated features. Real portal restrictions (CrazyGames/Poki) are more likely CSP connect-src or Permissions-Policy based, which a static local file can't easily replicate. This page is still useful for two real things:

  1. Confirming the game loads and plays fine inside a sandboxed iframe at all.
  2. Manually testing the new connection-timeout fallback: click Two phones → Host, note the room code, and don't open a second tab/peer. After ~25s the status message should switch to a "couldn't connect — falling back to single player" message and the mode buttons should return to 1-player — not hang forever on "waiting for them to join…".
